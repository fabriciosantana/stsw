# Atividade 05 — The Practical Test Pyramid

O objetivo foi seguir o [tutorial indicado no enunciado](https://martinfowler.com/articles/practical-test-pyramid.html). Consultei o artigo e seus exemplos de testes para uma aplicação Spring Boot.

Pontos observados:

- A pirâmide recomenda muitos testes de unidade, alguns testes de integração e poucos testes de ponta a ponta.
- Os exemplos de unidade organizam preparação, execução e verificação (*Arrange, Act, Assert*) e usam objetos simulados para isolar dependências.
- Os exemplos de integração verificam interações com banco de dados e serviços externos; os de ponta a ponta exercitam a aplicação pela interface ou API.

Não executei comandos da aplicação nem a suíte de testes do projeto de exemplo.
